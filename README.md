# Customer-Churn-Prediction-using-ANN
This project predicts customer churn whether a customer will leave a service or not using an Artificial Neural Network (ANN) built with deep learning techniques. Churn prediction is a binary classification task on structured/tabular data, which is common in customer relationship management (CRM) and telecom domains.

📝 Project Highlights Built a deep learning model using Keras/TensorFlow. Used an Artificial Neural Network (ANN) with fully connected layers to model the problem. Trained on structured customer data (features like credit score, tenure, balance, etc.). Achieved an accuracy of approximately 86% on the test dataset. Includes preprocessing steps like encoding categorical variables, feature scaling, and train-test split.

📁 Contents customer_churn_ann.ipynb — Jupyter notebook with full code: data preprocessing, model building, training, and evaluation. data/ — folder containing the dataset (or link to data if hosted elsewhere).

🚀 Technologies Used- Python, Keras & TensorFlow, Pandas & NumPy, Scikit-learn, Matplotlib & Seaborn (for visualization)

📊 Results- ✅ Accuracy on test data: ~86%, ✅ Model capable of identifying potential churners to help businesses take proactive action.
